# React Social Media Profile Cards – Day 10

Profile cards built with **React (Vite)** and **Bootstrap 5**.

## Run it
```bash
npm install
npm run dev
```

## Features
- Cover with an SVG mountain-and-road scene that fades into the card
- Bookmark button on the cover (toggle)
- Name, role and a Skills pill with icon badges
- Rating, posts and followers stats
- Follow / Following button that updates the follower count
- Three sample profiles in a responsive Bootstrap grid

## Files
- `src/data.js` – profile data (edit names, stats, skills here)
- `src/components/ProfileCard.jsx` – the card
- `src/components/Cover.jsx` – SVG cover scenes (desert, forest, dusk)
- `src/App.css` – styling on top of Bootstrap
